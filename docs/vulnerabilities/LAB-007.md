# LAB-007: Path Traversal (Arbitrary File Read)

## Overview
* **Vulnerability Name**: Path Traversal in Invoice Retrieval
* **Vulnerability ID**: LAB-007
* **OWASP Category**: A01:2021 — Broken Access Control
* **Location in Source Code**: `backend/app/api/orders.py` (`GET /api/orders/download/invoice`) & `backend/app/security/path_validator.py`

---

## Why It Is Vulnerable (Root Cause)
The invoice download endpoint joins a user-supplied filename parameter directly to a base directory without validating or canonicalizing the resulting path:
```python
# Insecure direct join
target_path = os.path.join(base_directory, requested_filename)
```
When directory traversal sequences (`../`) are supplied, the operating system resolves them by navigating up the filesystem hierarchy, allowing reads outside the intended invoice storage directory.

---

## Security Impact
- **Sensitive File Disclosure**: Reading application configuration files, `.env` files containing database credentials and secret keys, or system configuration files.
- **Credential Theft**: Exfiltrating application tokens and secrets.

---

## How to Reproduce Locally
1. Start the lab in vulnerable mode (`SECURE_MODE=false`).
2. Log in as user `alice`.
3. Navigate to the **Profile** view.
4. In the "Invoice Document Retrieval" input, enter:
   ```text
   ../../backend/app/config.py
   ```
5. Click **Fetch Document** or execute via curl:
   ```bash
   curl -H "Authorization: Bearer <token>" "http://localhost:8000/api/orders/download/invoice?filename=../../backend/app/config.py"
   ```

---

## Expected Insecure Behavior
The server returns `200 OK` with the raw Python source code of `backend/app/config.py` including `SECRET_KEY` and configuration logic.

---

## Secure Remediation
1. **Filename Sanitization**: Strip directory components using `os.path.basename()` and remove null bytes.
2. **Canonicalization**: Resolve the absolute canonical path using `os.path.realpath()` or `Path.resolve()`.
3. **Boundary Verification**: Ensure the resolved canonical path starts with the canonical base directory prefix (`target.startswith(canonical_base)`).

---

## Secure Code Example
```python
def resolve_safe_filepath(base_directory: str, requested_filename: str, secure_mode: bool = False) -> str:
    if not secure_mode:
        return os.path.join(base_directory, requested_filename)

    # 1. Strip traversal sequences and null bytes
    sanitized_filename = os.path.basename(requested_filename.replace("\x00", ""))
    
    # 2. Canonicalize real paths
    canonical_base = os.path.realpath(base_directory)
    target_path = os.path.realpath(os.path.join(canonical_base, sanitized_filename))
    
    # 3. Path boundary verification
    if not target_path.startswith(canonical_base):
        raise HTTPException(status_code=403, detail="Access denied: Path traversal detected.")
        
    return target_path
```
