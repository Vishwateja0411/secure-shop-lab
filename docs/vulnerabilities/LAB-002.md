# LAB-002: SQL Injection (Safe Local Search Lab)

## Overview
* **Vulnerability Name**: SQL Injection in Search Filter
* **Vulnerability ID**: LAB-002
* **OWASP Category**: A03:2021 — Injection
* **Location in Source Code**: `backend/app/api/products.py` (`GET /api/products/search`)

---

## Why It Is Vulnerable (Root Cause)
The product search endpoint dynamically constructs an SQL statement by formatting untrusted user input directly into the query string:
```python
unsafe_sql = f"SELECT id, name, description, price, stock, category, image_url FROM products WHERE name LIKE '%{q}%' OR description LIKE '%{q}%'"
result = db.execute(text(unsafe_sql))
```
Because user input is treated as executable code rather than data, metacharacters such as single quotes (`'`) break out of data literals and alter the SQL execution logic.

---

## Security Impact
- **Database Manipulation**: An attacker can bypass search filtering logic, execute arbitrary queries, enumerate database metadata, or extract confidential data.
- **Data Exfiltration**: In broader setups, unchecked SQL injection can result in full database dump or administrative account compromise.

---

## How to Reproduce Locally
1. Start the lab in vulnerable mode (`SECURE_MODE=false`).
2. Navigate to the SecureShop catalog.
3. In the search bar at the top, enter the classic SQL injection test pattern:
   ```text
   ' OR '1'='1
   ```
4. Click **Search** or send a GET request via curl:
   ```bash
   curl "http://localhost:8000/api/products/search?q='%20OR%20'1'='1"
   ```

---

## Expected Insecure Behavior
The SQL parser evaluates `OR '1'='1` to true for every database row, returning the complete catalog regardless of search keywords. If an unclosed quote is supplied (`'`), the server crashes with an exposed database syntax traceback.

---

## Secure Remediation
1. Use parameterized queries or ORM abstractions where user input is passed as bound parameters separate from query logic.
2. In SQLAlchemy, use the `.filter()` method with parameterized `.ilike()` expressions.

---

## Secure Code Example
```python
# Secure parameterized ORM query
pattern = f"%{q}%"
products = db.query(Product).filter(
    or_(
        Product.name.ilike(pattern),
        Product.description.ilike(pattern)
    )
).all()
```
