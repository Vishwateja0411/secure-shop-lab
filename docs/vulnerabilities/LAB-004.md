# LAB-004: Reflected Cross-Site Scripting (Reflected XSS)

## Overview
* **Vulnerability Name**: Reflected Cross-Site Scripting in Search Echo
* **Vulnerability ID**: LAB-004
* **OWASP Category**: A03:2021 — Injection (XSS)
* **Location in Source Code**: `backend/app/api/products.py` (`GET /api/products/search-echo`) & `frontend/js/app.js` (`handleSearch`)

---

## Why It Is Vulnerable (Root Cause)
The application takes the user-supplied `query` parameter and reflects it immediately into the response body or HTML DOM without validating or entity-encoding characters:
```javascript
// Vulnerable DOM assignment
reflectionTarget.innerHTML = `Showing results for: ${query}`;
```
Because the input is not sanitized or encoded, supplying HTML/script strings causes the browser's HTML parser to evaluate them as live code.

---

## Security Impact
- **Malicious Redirection & Phishing**: An attacker can construct a crafted link that, when clicked by a victim, executes client-side script in the victim's session context.
- **Client-Side Request Forgery**: The injected script can initiate actions on behalf of the victim.

---

## How to Reproduce Locally
1. Start the lab in vulnerable mode (`SECURE_MODE=false`).
2. In the navigation search bar, input:
   ```html
   <img src=x onerror="alert('Reflected XSS!')">
   ```
3. Press Enter or click **Search**.
4. Alternatively, request the echo API directly:
   ```bash
   curl "http://localhost:8000/api/products/search-echo?query=<script>alert(1)</script>"
   ```

---

## Expected Insecure Behavior
The banner reflects the raw `<img ...>` tag into the DOM, immediately triggering the script alert box.

---

## Secure Remediation
1. Encode all reflected output characters: `&` to `&amp;`, `<` to `&lt;`, `>` to `&gt;`, `"` to `&quot;`, `'` to `&#x27;`.
2. Use `element.textContent` rather than `innerHTML`.
3. Set the `Content-Security-Policy` header: `default-src 'self'`.

---

## Secure Code Example
```python
# Server-side remediation:
import html

def sanitize_search_query(query: str, secure_mode: bool = False) -> str:
    if not secure_mode:
        return query
    return html.escape(query, quote=True)
```

```javascript
// Client-side remediation:
reflectionTarget.textContent = `Showing results for: ${query}`;
```
